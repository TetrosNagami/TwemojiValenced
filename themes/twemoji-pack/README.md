# Twemoji Pack (Valenced)

1. Get the Twemoji PNGs (72x72) from the jdecked/twemoji repo (assets/72x72).
2. `node tools/build-emoji.mjs path/to/twemoji/assets/72x72`
3. Change `id` and `author` in manifest.json, then build/package as in the template.
